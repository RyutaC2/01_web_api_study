Position プロパティの挙動比較

各position値の違いを視覚的に理解するサンプルです。スクロールして挙動の違いを見てください。

1. position: static（デフォルト）

普通のflow。上から下へ流れていく。何も指定しないのと同じ。

box 1 (static)
box 2 (static)
box 3 (static)

2. position: relative

元の位置から相対的に移動。元の領域は占有したまま。

box 1 (relative, 動かない)
box 2 (relative, left: 50px; top: 20px;)
box 3 (relative, 動かない)
※ box 2 は移動したが、元の領域（グレーエリア）は占有したまま

3. position: absolute

DOM flow から外れて、親（親にposition: relativeが必要）を基準に配置される。

box 1 (static)
box 2 (absolute, top: 30px; left: 50px;)
box 3 (static)
※ box 2 はflow から外れているため、スペースを占有しない

4. position: fixed

ページ全体を基準に配置。スクロールしても位置が変わらない。

scrollable content 1
scrollable content 2
scrollable content 3
scrollable content 4
scrollable content 5
↓ 下のボックスはfixedです。このセクションをスクロールしても位置は変わりません ↓
Fixed Box (bottom-right)

5. position: sticky

最初はnormal flow。スクロール時に指定位置に「くっついて」固定される。

STICKY HEADER (top: 0;)
content 1
content 2
content 3
content 4
content 5
content 6
↑ 上のヘッダーをスクロールで「くっつく」様子を見てください ↑

まとめ

Position Flow から外れるか 基準位置 用途
static いいえ - 通常のレイアウト
relative いいえ 元の位置から相対的 親の基準位置設定、微調整
absolute はい 親（relative/absolute） モーダル、ツールチップ
fixed はい viewport（画面） navbar、サイドバー
sticky 部分的 最初は親、スクロール時は viewport テーブルヘッダー、セクションヘッダー

各セクションをスクロールして、position値の違いを体験してみてください！
