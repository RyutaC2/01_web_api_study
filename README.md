# Front-Back API Study Project

Next.js（フロントエンド）+ Go（バックエンド）でフルスタック開発を学習するためのプロジェクトです。

## 📚 学習ガイド

**最初に読むべきドキュメント**: [LEARNING_WORKFLOW.md](./LEARNING_WORKFLOW.md)

現状（HTML/CSS基礎あり、JS未経験、TS未経験）からの効率的な学習パスが記載されています。

## 📁 プロジェクト構成

```
front_back_api/
├── README.md              # このファイル
├── LEARNING_WORKFLOW.md   # 学習ワークフロー（要読）
├── front_end/             # Next.js フロントエンド
└── back_end/              # Go バックエンド
```

## 🚀 クイックスタート

### フロントエンド（Next.js）
```bash
cd front_end
npm install
npm run dev
# http://localhost:3000 でアクセス
```

### バックエンド（Go）
```bash
cd back_end
go run main.go
# http://localhost:8080 でアクセス
```

## 🎯 プロジェクト目標

1. Next.js + TypeScript の基本習得
2. Go でのシンプルな REST API 実装
3. フロント・バックエンド間の通信実装
4. 実装を通じた JavaScript/TypeScript学習

## 📖 主な学習段階

1. **Phase 1**: Next.js 環境構築
2. **Phase 2**: TypeScript/JavaScript 基礎
3. **Phase 3**: Next.js API ルート
4. **Phase 4**: Go バックエンド構築
5. **Phase 5**: 使い分けの理解
6. **Phase 6**: 統合プロジェクト（Todo アプリ）

詳細は [LEARNING_WORKFLOW.md](./LEARNING_WORKFLOW.md) を参照。
